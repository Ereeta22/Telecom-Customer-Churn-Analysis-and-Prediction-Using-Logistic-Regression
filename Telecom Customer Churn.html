Telecom Customer Churn Analysis and Prediction Using Logistic Regression¶

Introduction¶

This project focuses on analyzing customer behaviour and predicting customer churn in the telecom industry.¶

Customer churn occurs when a customer stops using a company's services.¶

The project uses Python libraries such as Pandas, NumPy, Matplotlib, Seaborn, SciPy and Scikit-learn for data cleaning, data analysis,¶

visualization and machine learning.¶

Logistic Regression is used to predict whether a customer will continue or discontinue the service.¶

The main objective is to identify factors associated with customer churn and help the company improve customer retention.¶
